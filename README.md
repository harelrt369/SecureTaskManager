Secure Task Manager 🛡️ - הסבר

אודות הפרויקט: 
מערכת לניהול משימות מאובטחת בארכיטקטורת שרת-לקוח (Client-Server). הפרויקט מדגים יישום מעשי של תקשורת רשת, הצפנה מתקדמת, תכנות מונחה עצמים (OOP) וממשק משתמש (GUI). המערכת מאפשרת למספר משתמשים להתחבר לשרת מרכזי, להוסיף משימות ולצפות בהן, והכל תחת מעטפת אבטחה מחמירה. 

טכנולוגיות ויכולות מרכזיות:
תקשורת (TCP Sockets): 
הפרויקט מבוסס על סוקטים (Sockets) ומבטיח העברת נתונים אמינה בין השרת ללקוחות ברשת בעזרת פרוטוקול הודעות ייעודי.
אבטחה והצפנה היברידית:
1.שימוש ב-RSA (הצפנה א-סימטרית) לביצוע "לחיצת יד" מאובטחת ושיתוף מפתח בסתר.
2.שימוש ב-AES (הצפנה סימטרית) להצפנה מהירה של כל התעבורה השוטפת.
3.המערכת חסינה למתקפות רחרוח והאזנה (Sniffing) ומתקפות אדם-באמצע (MITM).
ריבוי לקוחות (Threading): 
השרת מנהל כל לקוח בתהליכון (Thread) נפרד, מה שמאפשר למספר משתמשים לעבוד מול השרת במקביל מבלי לתקוע את המערכת.
ממשק משתמש (Tkinter): 
צד הלקוח כולל ממשק גרפי מלא, נוח ואינטראקטיבי, המאפשר הוספת משימות בעברית עם תמיכה ביישור טקסט (RTL).
מערכת הפעלה וקבצים: 
השרת ניגש למערכת הקבצים שומר את רשימת המשימות לקובץ טקסט מקומי, כדי למנוע אובדן נתונים במקרה של כיבוי השרת.

מבנה הקוד (OOP) 
הקוד מאורגן בתכנות מונחה עצמים (Object-Oriented) ומחולק למחלקות לוגיות ברורות: 
Server - מחלקה לניהול תעבורת הרשת והלקוחות.
Client - מחלקה לניהול החיבור והבקשות מצד המשתמש.
Security - מחלקה המאגדת את פונקציות ההצפנה (יצירת מפתחות, קידוד ופענוח).
GUI - מחלקה לאפיון וניהול חלון התצוגה.

הוראות הרצה
1.ודאו שמותקנת על המחשב סביבת Python וספריית cryptography.
2.הריצו תחילה את קובץ השרת: python server.py. השרת יתחיל להאזין לחיבורים נכנסים.
3.הריצו את קובץ הלקוח: python client.py (ניתן לפתוח מספר חלונות לקוח במקביל).
